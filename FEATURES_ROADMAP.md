# TT ERP Roadmap

## Included in this local MVP
- Local SQLite database, auto-created on first run
- Dashboard and generic CRUD for 14 ERP areas
- Search, edit and delete records
- CSV and XLSX exports
- CSV/XLSX import into a selected module
- Voice-based module navigation in supported browsers
- API health and diagnostics endpoints

## Next production milestones
1. Separate normalized tables and validation for each module.
2. User login, password hashing, roles and permissions.
3. Accounting, GST, invoices, payment allocation and audit logs.
4. Inventory transactions, batches, roll/lot tracking and stock valuation.
5. Flexible packaging workflows: BOM, production orders, DPR, SFG store, packing, QR labels and dispatch.
6. AI integration with explicit provider/API key configuration and permission-gated actions.
7. Automated tests, backups, migrations, logging, and secure deployment.
